# jogo_2D
jogo para treinar usar o GitHub com o titio vivi/Leonardo DiCaprio.

25/08 - Hoje aprendemos a utilizar o GitHub, utilizando os recursos para a criação do jogo, Versionamento de código e aprendemos a utilizar os comandos: Pull, Branch, commit e outros. Durante a utilização do GitHub Desktop criamos a branch: "testes". No jogo adicionamos um Player e 3(Três) plataformas no jogo.

27/08 - Hoje aprendemos sobre um aparte da Game Design, assuntos como o que é o Game Design e sobre o Game Design de Mecânica, vimos um video sobre um jogo chamado  HOB, ele falava sobre como o jogo é um exemplo de Game Design, também começamos a preencher o GDD que seria um documento sobre o jogo na qual estamos fazendo.
